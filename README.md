# student-management-system
A department relational database system designed and implemented using MYSQL to manage student enrollments, academic departments, courses, and faculty.

## Project Overview
This project focuses on modeling, designing, and querying a structured relational database for an academic institution. The system was built to handle core administrative data including tracking student enrollments, assigning faculty to courses, and organizing academic departments while maintaining strict data integrity.
